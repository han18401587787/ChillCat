# 绪安 v3.0 产品需求文档

> 激发大众心理同情 · 更好的倾听、处理、传播情绪价值

---

## 一、产品定位与愿景

### 1.1 一句话定位
**绪安——让每一种情绪都被接住、被理解、被温柔回应。**

### 1.2 产品愿景
成为华语世界最温暖的情绪治愈平台。不是冷冰冰的工具，而是一个能「倾听你、理解你、陪你走出来」的数字化朋友。

### 1.3 从 v2.0 到 v3.0 的跨越

| 维度 | v2.0（当前） | v3.0（目标） |
|:--|:--|:--|
| 核心动作 | 记录情绪 | **倾听→处理→传播** 全链路 |
| 主要交互 | 单人打卡 | **AI倾听 + 社区共鸣 + 情绪传播** |
| 用户价值 | 了解自己的情绪 | **被理解、被回应、被治愈** |
| 社会价值 | 个体关怀 | **激发大众心理同情，构建情绪支持网络** |

## 二、核心价值主张

绪安 v3.0 围绕「情绪价值」的三个维度构建产品能力：

```
        ┌──────────────────────────────────────┐
        │           绪安 v3.0 情绪价值环        │
        │                                      │
        │    倾听 ◄──────────► 处理            │
        │   (LISTEN)          (PROCESS)        │
        │     │                  │              │
        │     └────── 传播 ──────┘              │
        │           (SPREAD)                   │
        └──────────────────────────────────────┘
```

### 2.1 倾听（LISTEN）
> "我不需要你解决问题，我只需要你听我说。"

- **AI 情绪倾听官**：不再是冰冷表单，而是能理解语气、分析情绪状态、给出共情回应的 AI
- **语音情绪日记**：用户说话，AI 识别情绪类型和强度，自动生成情绪标签
- **树洞 2.0**：从异步文字帖子升级为实时情感连接——收到回应时收到通知+共鸣提示

### 2.2 处理（PROCESS）
> "情绪不是敌人，是信使。学会解读它。"

- **情绪解码器**：输入一句话，AI 拆解背后的情绪层次（表层→中层→深层需求）
- **个性化治愈计划**：根据近 30 天情绪数据自动生成「稳情计划」，推荐冥想/课程/练习
- **情绪预警**：识别情绪恶化趋势（如连续 5 天负面），主动推送关怀+专业求助建议

### 2.3 传播（SPREAD）
> "你的故事可能正是一个陌生人需要的勇气。"

- **情绪共鸣墙**：用户授权的情绪日记匿名展示，他人可以「共鸣」而非「点赞」
- **鼓励链**：一人发起鼓励，陌生人接力传递——形成温暖的数字接力棒
- **感谢信**：对帮助过你的人写感谢信，可选择匿名寄出或公开发布

## 五、详细功能需求

### 5.1 倾听模块：AI 情绪倾听官 🎧

| 功能 | P级 | 描述 |
|:--|:--|:--|
| **语音情绪日记** | P0 | 用户口述当日情绪，AI 语音识别+情绪分析，自动标注情绪类型和强度（平静/轻度/中度/重度），生成结构化日记 |
| **AI 共情回应** | P0 | 用户写下情绪后，AI 自动生成 3-5 句温暖回应。不是解决问题，而是说「我听到了」「这很正常」「你辛苦了」。每条回应附带不同的情绪角度 |
| **情绪语气分析** | P1 | 用户输入文字，AI 分析语气中的隐藏情绪（愤怒→底层可能是受伤，焦虑→底层可能是失控感） |
| **智能追问** | P1 | AI 根据用户输入自动追问：「发生什么让你有这种感觉？」「这种感觉持续多久了？」引导更深层次的情绪表达 |
| **倾听官形象** | P2 | 可选的 AI 倾听官角色（温柔的猫/沉稳的树/温暖的光），每个角色有不同的回应风格 |

**场景示例：**
> 用户输入：「今天又被老板批了。」
>
> AI 回应：
> 💚 「听起来你今天承受了不少压力。被批评的感觉确实不好受。」
> 🌿 「你已经很努力了。有时候批评不是否定你的全部。」
> 🕊️ 「愿意再多说一点吗？我在这里听着。」

### 5.2 处理模块：情绪解码器 🧠

| 功能 | P级 | 描述 |
|:--|:--|:--|
| **情绪解码** | P0 | 输入一段情绪描述，AI 拆解：表层情绪→中层情绪→深层需求。例如「愤怒」→「感到不公」→「需要被尊重」 |
| **稳情计划** | P0 | 基于用户近 30 天情绪数据，AI 自动生成一周治愈计划：每天一个任务（冥想/写日记/散步/给朋友打电话） |
| **情绪预警** | P1 | 连续 3 天负面情绪 → 关怀提醒；连续 7 天 → 推送专业求助建议；检测到自伤倾向 → 危机干预提示 |
| **情绪模式报告** | P1 | 月度/季度报告：哪些场景触发负面情绪？哪些活动改善情绪？关联分析（睡眠/天气/社交与情绪的关系） |
| **CBT 自助工坊** | P2 | 认知行为疗法的自助练习：思维记录表、证据检验、替代性思维生成 |

**场景示例：**
> 用户记录：「我又在凌晨三点醒来，想到下个月要绩效考核就开始心慌。」
>
> 绪安解码：
> - 表层：焦虑
> - 中层：对不确定性的恐惧、完美主义倾向
> - 深层：需要安全感、需要自我肯定
>
> 建议：今晚尝试「4-7-8呼吸法」助眠 + 明天写一篇「我过去的成功经历」重建自信

### 5.3 传播模块：共鸣墙 & 鼓励链 🌈

| 功能 | P级 | 描述 |
|:--|:--|:--|
| **共鸣墙** | P0 | 用户授权的匿名情绪日记展示在共鸣墙。其他人可以「共鸣」（非点赞），表达「我也有过这种感觉」「你并不孤单」。算法匹配相似情绪经历的内容 |
| **鼓励链** | P0 | 「今天我想鼓励每一个焦虑的人」→ 下一个人接上 → 形成温暖的接力链。每条最多 140 字，纯善意 |
| **感谢信** | P1 | 给生命中值得感谢的人写一封信。可匿名寄出（APP内通知）或公开发布在共鸣墙。收信人可以看到并回复 |
| **情绪地图** | P1 | 匿名展示全国用户情绪分布（城市级别模糊化）。不是为了窥探，而是传达「你不是一个人」——此时此刻，有 83,247 个人和你一样感到焦虑 |
| **每日暖心推送** | P2 | 每天推送一位用户的匿名治愈故事+一句暖心语录。用户可选择开启/关闭 |

**场景示例：**
> 用户小雅在共鸣墙看到一条匿名帖子：「三十岁生日一个人过的，给自己买了个小蛋糕。有点孤独，但也挺自由的。」
>
> 小雅点击「共鸣」→ 写下：「我也是！三十岁一个人过的。自由比什么都重要 🍰」
>
> 原帖作者收到通知：「有人在你的故事里找到了共鸣。」
>
> 两个人，因为共享一种情绪，在数字世界里短暂相遇了。

### 5.4 社区规则与安全

| 规则 | 说明 |
|:--|:--|
| **不评判原则** | 共鸣墙和树洞禁止批评、嘲讽、说教。只允许表达支持和理解 |
| **AI 内容审核** | 所有发布内容经过 AI 审核，过滤暴力、自伤、违法内容 |
| **危机干预** | 检测到自伤倾向 → 自动弹出求助热线（全国心理援助热线：400-161-9995） |
| **青少年保护** | 22:00-06:00 自动开启「静夜模式」：减少推送、增加助眠引导 |
| **数据匿名化** | 共鸣墙和情绪地图的数据经过三层匿名处理，无法追溯到个人 |

## 六、技术架构建议

```
┌─────────────────────────────────────────┐
│              iOS Client                 │
│  SwiftUI + Combine + AI Local Inference │
└──────────────────┬──────────────────────┘
                   │ HTTPS
┌──────────────────▼──────────────────────┐
│           API Gateway (Nginx)           │
└──────────────────┬──────────────────────┘
                   │
┌──────────────────▼──────────────────────┐
│           Go Service (Gin)              │
│  Auth · Emotion · Treehole · AI Proxy   │
└──────┬──────────────────┬───────────────┘
       │                  │
┌──────▼──────┐   ┌───────▼──────────────┐
│ PostgreSQL  │   │  AI Service (Python)  │
│ (主数据库)   │   │  NLP 情绪分析         │
└─────────────┘   │  推荐匹配  内容审核     │
                  └──────────────────────┘
```

**关键技术决策：**

| 决策 | 方案 | 理由 |
|:--|:--|:--|
| AI 情绪分析 | 国内 NLP 大模型 API（百度/讯飞/阿里） | 中文情绪识别准确度高、合规 |
| 实时推送 | WebSocket + APNs | 共鸣通知需要实时性 |
| 内容审核 | NLP 模型 + 敏感词库 | 社区安全底线 |
| 情绪地图 | 差分隐私 | 保护用户位置隐私 |
| 语音识别 | 本地 Whisper + 云端兜底 | 隐私优先，降级保证可用 |
