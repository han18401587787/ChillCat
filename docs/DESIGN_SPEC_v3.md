## 一、全局设计系统

### 1.1 色彩体系

```
品牌色（蓝灰系）
├── primary:    #5A7A8A  主按钮、标题
├── primary-light: #7A9AAA  次级文字、辅助
└── primary-muted: #B8D4E3  背景装饰、选中态

治愈暖色
├── warm:       #8B6F47  会员金色
├── warm-light: #C9A063  高亮文字
└── soft-pink:  #E8B8C8  爱心、关怀

功能色
├── soft-green: #66BB6A  打卡成功、完成
├── soft-purple:#D4C8E8  冥想、治愈
├── error:      #E57373  删除、警告
└── bg:         #F9F6F2  页面背景
```

### 1.2 字体层级

| 级别 | 大小 | 字重 | 用途 |
|:--|:--|:--|:--|
| H1 | 28px | Bold | 页面标题 |
| H2 | 22px | Bold | 模块标题 |
| H3 | 18px | Semibold | 卡片标题 |
| Body | 15px | Regular | 正文 |
| Caption | 13px | Regular | 辅助说明 |
| Small | 11px | Regular | 标签、时间 |

### 1.3 圆角与间距

| Token | 值 | 用途 |
|:--|:--|:--|
| radius-sm | 8px | 标签、小卡片 |
| radius-md | 12px | 按钮、输入框 |
| radius-lg | 16px | 卡片 |
| radius-xl | 24px | 大容器 |
| spacing-sm | 8px | 紧凑间距 |
| spacing-md | 16px | 标准间距 |
| spacing-lg | 24px | 模块间距 |

### 1.4 图标系统
- SF Symbols 6 (iOS 18+) 为主
- 自定义绪安表情包（24 款，见 §8.1）
- 所有图标使用 `.foregroundColor(primary)` 统一着色

## 二、新增页面设计规格

### 2.1 AI 情绪倾听官 — 首页嵌入

**位置：** 首页情绪打卡区域上方
**尺寸：** 全宽卡片，高度自适应（150-250px）

```
┌─────────────────────────────────┐
│  🎧 今天想和我说什么？          │ ← H3
│  ┌───────────────────────────┐  │
│  │ 随便说说，我在听…         │  │ ← 多行输入框
│  │                           │  │    placeholder 灰色
│  │                     🎤 ✨  │  │ ← 语音/发送按钮
│  └───────────────────────────┘  │
│                                 │
│  💚 「被批评的感觉确实不好受。」 │ ← AI 回应气泡
│  🌿 「你已经很努力了。」        │    浅绿背景，圆角
│  🕊️ 「愿意多说一点吗？」      │    逐条动画出现
└─────────────────────────────────┘
```

**交互规则：**
- 用户输入 ≥ 3 个字 → 发送按钮激活
- 点击发送 → 3 条 AI 回应依次出现（延迟 0.8s/条）
- 语音按钮 → 跳转语音情绪日记页
- AI 回应可点击「有用 / 不太对」，用于训练模型

**状态：**
- 加载中：输入框下方显示脉动圆点（...）
- 空输入：placeholder 文字轮播（「今天发生了什么？」「有什么想说的？」「我在这里听」）
- 错误：显示「AI 暂时不在，请稍后再试」

### 2.2 语音情绪日记

**入口：** 首页 AI 倾听官 → 🎤 按钮 / 首页浮动按钮

```
┌─────────────────────────────────┐
│  ← 语音日记                     │
│                                 │
│         ┌───────────┐           │
│         │   🎤      │           │ ← 录音按钮（大圆）
│         │  按住说话  │           │    按下时缩放动画
│         └───────────┘           │
│                                 │
│  波形动画 ▂▃▅▇▅▃▂▃▅▇▅▃▂▃▅▇    │ ← 实时音量波形
│                                 │
│  00:32                          │ ← 录音时长
│  ● (录制中)                     │ ← 红点闪烁
│                                 │
│  ┌───────────────────────────┐  │
│  │ 💚 情绪识别: 焦虑 85%      │  │ ← AI 分析结果
│  │ 📝 转文字: "今天开会..."   │  │
│  │ 🏷️ 标签: #职场 #压力      │  │
│  └───────────────────────────┘  │
│                                 │
│  [重新录制]  [保存日记]         │ ← 底部按钮
└─────────────────────────────────┘
```

**交互规则：**
- 按住录音 → 实时波形 + 计时
- 松开 → 停止录音 → AI 分析（loading 1-2s）→ 显示结果
- 转文字可手动编辑
- 情绪标签可手动增删

### 2.3 共鸣墙

**入口：** Tab 栏第 5 位（新增）或首页入口

```
┌─────────────────────────────────┐
│  共鸣墙        🕊️ 12,847 人此刻  │
│                                 │
│  ┌─────────────────────────┐    │
│  │ 🟢 平静 · 2小时前        │    │ ← 情绪色点
│  │                         │    │
│  │ 三十岁生日一个人过的，   │    │
│  │ 给自己买了个小蛋糕。     │    │
│  │ 有点孤独，但也挺自由的。 │    │
│  │                         │    │
│  │ 💚 2,341 人共鸣          │    │ ← 共鸣数（非点赞）
│  │ [我也想说] [分享共鸣]    │    │
│  └─────────────────────────┘    │
│                                 │
│  ┌─────────────────────────┐    │
│  │ 🟡 焦虑 · 5小时前        │    │
│  │                         │    │
│  │ 下周一就答辩了，PPT 改   │    │
│  │ 了八遍了还是不满意。     │    │
│  │                         │    │
│  │ 💚 892 人共鸣            │    │
│  │ [我也想说] [分享共鸣]    │    │
│  └─────────────────────────┘    │
│          ↓ 上拉加载更多         │
└─────────────────────────────────┘
```

**卡片设计：**
- 左侧情绪色条（4px 宽，对应情绪颜色）
- 顶部：情绪标签 + 发布时间
- 中间：文字内容（最多 280 字，超过折叠）
- 底部：共鸣数 + 互动按钮
- 点击卡片 → 全屏详情（可以看到更多共鸣回应）

**交互规则：**
- 「共鸣」不是点赞——点击后出现"我也有过这种感觉"，可选择附上一句鼓励
- 下拉刷新 → 新内容
- 算法：优先展示与自己情绪类型匹配的内容

## 三、页面流程（新增）

```
主页（升级）
├── AI倾听官 → AI 回应 → 情绪打卡完成
├── 语音日记 → 录音 → AI分析 → 保存
├── 共鸣墙入口 → 共鸣墙
├── 鼓励链入口 → 鼓励链
└── 情绪解码入口 → 情绪解码器

共鸣墙
├── 浏览共鸣 → 点击卡片 → 共鸣详情
├── 表达共鸣 → 写鼓励 → 发送
└── 上拉加载更多

鼓励链
├── 查看链 → 参与接力 → 写鼓励 → 发送
└── 我的链 → 参与过的链列表

情绪解码器
├── 输入情绪 → AI分析 → 三层拆解 → 建议
└── 保存到日记
```

## 五、设计约束

- 所有页面 390×844 pt 基准（iPhone 14/15/16 标准尺寸）
- 支持 Dark Mode（自动切换背景色）
- 所有交互按钮最小触控区域 44×44 pt
- 列表项高度 ≥ 60pt（便于单手操作）
- 文字层级不超过 3 级
- 动画时长 ≤ 300ms（保持流畅感）
- 所有颜色对比度 ≥ WCAG AA 标准
