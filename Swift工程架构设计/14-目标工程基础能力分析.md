### 1.3 未识别方法防护（Unrecognized Selector）

通过 `forwardInvocation` + `methodSignatureForSelector:` 拦截所有未识别的方法调用，防止 `unrecognized selector sent to instance` 崩溃。

```objc
// 核心实现模式
- (void)forwardInvocation:(NSInvocation *)invocation {
    if ([self respondsToSelector:[invocation selector]]) {
        [super forwardInvocation:invocation];
    } else {
        // 记录错误日志，但不崩溃
        invocation.target = nil;
        [invocation invoke];
    }
}

- (NSMethodSignature *)methodSignatureForSelector:(SEL)selector {
    NSMethodSignature *sig = [super methodSignatureForSelector:selector];
    if (sig) return sig;
    // 返回一个默认签名，避免 crash
    sig = [NSMethodSignature signatureWithObjCTypes:"@^v^c"];
    return sig;
}
```

### 1.4 防护启动机制

- **延迟启动**：支持配置延迟时间（默认 3 秒）
- **快速启动**：低版本系统快速开启
- **配置控制**：通过 `KWGlobalControlCenter` 按功能开关控制
- **Debug 模式**：延迟 50 秒后启动，方便开发调试
- **上次崩溃检测**：上次启动崩溃则不开启快速启动

```objc
KW_Registe_Function_MainThread(KWKylin_LifeCycle_WillFinishLaunch) {

```

## 十六、总结：Swift 工程基础能力映射

### 16.1 必须实现的基础能力

| 优先级 | 能力模块 | Swift 实现方案 |
|--------|----------|---------------|
| **P0** | 容器安全防护 | 使用 Swift 原生安全特性 + 扩展方法 |
| **P0** | 字符串安全操作 | String 扩展，边界检查 |
| **P0** | 未识别方法防护 | Swift 编译期检查，无需运行时防护 |
| **P0** | 主线程检查 | `@MainActor` + DispatchQueue 检查 |
| **P0** | 日志系统 | OSLog 封装 + 日志级别控制 |
| **P0** | 网络请求封装 | URLSession + async/await |
| **P0** | Keychain 存储 | Keychain Services API 封装 |
| **P0** | 安全类型转换 | 泛型方法 + 协议约束 |
| **P1** | 屏幕适配 | 基于 Point 的适配工具 |
| **P1** | 路由系统 | Coordinator + URL Scheme |
| **P1** | 事件总线 | Combine / AsyncSequence |
| **P1** | 缓存系统 | NSCache + 文件缓存 |
| **P1** | 任务管理 | Task + TaskGroup |
| **P1** | Timer 安全 | `AsyncSequence` timer / weak Timer |
| **P2** | 数据库 | SwiftData / CoreData |
| **P2** | 文件管理 | FileManager 封装 |
| **P2** | 图片处理 | Image I/O + Core Image |
| **P2** | 日期工具 | DateFormatter 封装 |
| **P2** | 设备信息 | UIDevice 扩展 |
| **P2** | 网络状态监听 | NWPathMonitor 封装 |

### 16.2 Swift 特有优势（无需 OC 中的防护）

| OC 防护点 | Swift 天然优势 |
|-----------|---------------|
| `nil` 参数防护 | Swift 可选类型，编译期检查 |
| 数组越界 | Swift Array 越界仍会崩溃，需用 safe 扩展 |
| 字典 nil key | Swift Dictionary key 非可选 |
| unrecognized selector | Swift 无运行时消息转发 |
| `performSelector` 泄漏 | Swift 不支持 performSelector |
| 类型安全 | Swift 强类型，编译期检查 |
| 内存管理 | ARC + 值类型，循环引用更少 |

### 16.3 Swift 中仍需重点防护的领域

| 风险点 | 防护方案 |
|--------|----------|
| **Array 越界** | `safe[index]` 扩展返回 Optional |
| **Dictionary 类型安全** | 泛型 + 类型检查 |
| **String 越界** | `safe` 下标扩展 |
| **JSON 解析失败** | `Result` 类型 + 错误处理 |
| **主线程 UI 更新** | `@MainActor` + `MainActor.run` |
| **循环引用** | `[weak self]` + `weak`/`unowned` |
| **除零错误** | 安全除法函数 |
| **可选值强制解包** | 规范禁止 `!`，使用 `guard let` |
| **并发数据竞争** | Actor + Sendable |
| **Timer 循环引用** | `AsyncSequence` timer 或 weak self |
