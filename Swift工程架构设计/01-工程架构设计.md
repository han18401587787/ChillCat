## 1. 整体架构分层

### 1.1 四层架构总览

```
┌─────────────────────────────────────────────────────────────┐
│                     Presentation Layer                       │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────┐  │
│  │  Views / UI  │  │  ViewModels  │  │   Coordinators   │  │
│  │  (SwiftUI)   │  │  @Observable │  │    / Routers     │  │
│  └──────────────┘  └──────────────┘  └──────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│                     Domain Layer                             │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────┐  │
│  │   UseCases   │  │   Entities   │  │ RepositoryProtocol│  │
│  │  (业务用例)   │  │  (业务实体)   │  │   (仓库协议)      │  │
│  └──────────────┘  └──────────────┘  └──────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│                      Data Layer                              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────┐  │
│  │ Repositories │  │     DTOs     │  │   DataSources     │  │
│  │  (仓库实现)   │  │  (数据传输)   │  │ (Remote/Local)   │  │
│  └──────────────┘  └──────────────┘  └──────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│                   Core / Foundation Layer                    │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────┐  │
│  │  Networking  │  │   Storage    │  │  Extensions /    │  │
│  │  (网络封装)   │  │  (存储封装)   │  │  Utils (工具)    │  │
│  └──────────────┘  └──────────────┘  └──────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 分层职责与依赖规则

| 层级 | 职责 | 可依赖 | 不可依赖 |
|------|------|--------|----------|
| **Presentation** | UI 展示、用户交互、页面路由 | Domain | Data、Core |
| **Domain** | 业务逻辑、实体定义、协议定义 | 无（纯 Swift） | UIKit/SwiftUI |
| **Data** | 数据获取、DTO 转换、缓存策略 | Domain、Core | Presentation |
| **Core** | 基础能力封装 | 无 | 任何业务层 |

### 1.3 依赖方向

```
Presentation → Domain ← Data → Core
```

- **Presentation** 依赖 **Domain**（通过 UseCase 协议）
- **Data** 依赖 **Domain**（实现 Repository 协议）
- **Data** 依赖 **Core**（使用网络/存储能力）
- **Domain** 不依赖任何其他层（纯 Swift 代码）

## 2. 目录结构规范

### 2.1 标准目录模板

```
ProjectName/
├── App/                              # App 入口
│   ├── App.swift                     # @main 入口

│   └── AppDependencyContainer.swift  # 依赖容器组装

│   ├── Networking/                   # 网络层
│   ├── Storage/                      # 存储层

│   ├── Extensions/                   # 扩展

│
├── Domain/                           # 领域层

│   └── RepositoryProtocols/          # 仓库协议
│

│   ├── Repositories/                 # 仓库实现
│   ├── DataSources/                  # 数据源
│   │   ├── Remote/                   # 远程数据源

│   └── DTOs/                         # 数据传输对象
│
├── Presentation/                     # 展示层
│   ├── Common/                       # 公共组件

│   ├── Modules/                      # 功能模块
│   │   ├── Auth/                     # 认证模块
│   │   ├── Home/                     # 首页模块
│   │   └── ...                       # 其他模块
│   └── Navigation/                   # 导航路由
│
├── Resources/                        # 资源文件
│   ├── Assets.xcassets
│   ├── Colors.xcassets
│   ├── Fonts/
│   └── Localization/
│
├── Tests/                            # 测试
│   ├── UnitTests/
```

### 2.2 文件命名规范

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| View | `{Module}View` | `LoginView.swift` |
| ViewModel | `{Module}ViewModel` | `LoginViewModel.swift` |
| Coordinator | `{Module}Coordinator` | `AuthCoordinator.swift` |
| UseCase | `{Action}UseCase` | `LoginUseCase.swift` |
| Entity | `{Entity}` | `User.swift` |
| Repository | `{Entity}Repository` | `UserRepository.swift` |
| DataSource | `{Entity}{Type}DataSource` | `UserRemoteDataSource.swift` |
| DTO | `{Entity}DTO` | `UserDTO.swift` |
| Protocol | `{Name}Protocol` | `UserRepositoryProtocol.swift` |

## 3. 环境配置

### 3.1 多环境支持

```swift
enum AppEnvironment {
    case development
    case staging
    case production

    static var current: AppEnvironment {
        #if DEBUG
        return .development
        #else
        return .production
        #endif
    }

    var baseURL: URL {
        switch self {
        case .development:
            return URL(string: "https://dev-api.example.com")!
        case .staging:
            return URL(string: "https://staging-api.example.com")!
        case .production:
            return URL(string: "https://api.example.com")!
        }
    }

    var logLevel: LogLevel {
        switch self {
        case .development: return .debug
        case .staging: return .info
        case .production: return .error
        }
    }
}
```

### 3.2 Build Configuration

在 Xcode 中配置以下 Build Configuration：

| 配置名 | 用途 | 基于 |
|--------|------|------|
| Debug | 开发调试 | Debug |
| Staging | 测试验证 | Release |
| Release | 正式发布 | Release |

每个 Configuration 设置不同的 `SWIFT_ACTIVE_COMPILATION_CONDITIONS`：

- Debug: `DEBUG`
- Staging: `STAGING`
- Release: （无）

## 4. App 入口规范

### 4.1 SwiftUI App 入口

```swift
// App/App.swift

import SwiftUI

@main
struct ProjectApp: App {
    @StateObject private var coordinator: AppCoordinator

    init() {
        let diContainer = AppDependencyContainer()
        _coordinator = StateObject(
            wrappedValue: AppCoordinator(diContainer: diContainer)
        )
    }

    var body: some Scene {
        WindowGroup {
            coordinator.buildRootView()
                .environmentObject(coordinator)
        }
    }
}
```
